# Family Wealth Dashboard — Privacy-Safe Portfolio Demo

A standalone, responsive HTML portfolio demonstration of an AI-assisted personal financial dashboard project.

## What this demonstrates
- User-focused dashboard interface and responsive design
- Sample asset-allocation visualization and tabbed navigation
- Iterative prototyping and AI-assisted development

## Privacy
All displayed account names, balances and performance values are masked. Any chart values are fabricated demonstration data. This repository contains **no real financial account connections or credentials**.

This is a **simplified public showcase**, not the full private dashboard.

## Publish with GitHub Pages
1. Create a **public** GitHub repository (for example `family-wealth-portfolio-demo`).
2. Upload `index.html` and `README.md` to the repository root.
3. In repository **Settings → Pages**, select **Deploy from a branch**, branch **main**, folder **/(root)**, and Save.
4. Wait for GitHub to show the published site URL; open it and check that the tabs and charts work.
5. Submit that **actual published URL** in the MemoMind developer beta application.

The published address typically follows `https://USERNAME.github.io/REPOSITORY/`, but verify the actual address shown by GitHub before submitting.
